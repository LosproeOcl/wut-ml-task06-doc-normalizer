# 分析脚本目录说明

本目录用于探索性分析，不作为最终结论的载体。

## 使用规则

1. Notebook 仅用于数据探索、参数试验与绘图草稿。
2. 报告中引用的全部数值须能由 `src/` 下的脚本复现。
3. 提交前清空输出，或仅保留关键图表。
4. Notebook 文件命名采用 `序号-主题.ipynb`，例如 `01-数据分布统计.ipynb`。
5. 不得在 Notebook 中硬编码本地绝对路径。

## 计划内容

| 序号 | 主题 | 产出 |
|---|---|---|
| 01 | 数据分布统计 | 类别、角度、光照与分辨率分布图 |
| 02 | 矫正效果检查 | 四角检测成功与失败样本抽查 |
| 03 | 增强效果对比 | 增强前后的目视对比与清晰度指标 |
| 04 | 特征可视化 | 传统特征的分布与重要性 |
| 05 | 错误案例分析 | 错误样本归集与原因标注 |
