# 源码目录说明

当前处于 M0 阶段，本目录仅保留结构说明，不包含实现代码。

## 计划结构

```text
src/docnorm/
├── __init__.py
├── cli.py              命令行入口
├── pipeline.py         单图处理链路
├── data/
│   ├── manifest.py     清单校验与索引
│   ├── split.py        分组划分
│   └── loader.py       图像读取与预处理
├── rectify/
│   ├── detector.py     四边形检测
│   └── warp.py         顶点排序与透视变换
├── enhance/
│   └── clahe.py        直方图均衡与去阴影
├── features/
│   └── classic.py      传统特征提取
├── classify/
│   ├── classic.py      支持向量机与随机森林
│   └── cnn.py          MobileNetV3 迁移学习
├── eval/
│   ├── metrics.py      指标计算
│   └── runner.py       实验编排
├── privacy/
│   ├── detector.py     人脸与二维码候选检测
│   ├── mask.py         区域填充与元数据去除
│   └── audit.py        复核记录与审计
└── viz/
    └── figures.py      图表绘制
```

## 实现约定

1. 模块职责与输入输出以 `docs/03-架构设计.md` 第 4 节为准。
2. 模块之间通过数据结构通信，不共享全局状态。
3. 公共函数须提供类型注解与文档字符串。
4. 不得在库代码中使用 `print`，日志统一使用 `logging`。
5. 所有涉及随机性的入口须接受随机种子参数。

## 开发顺序

建议按以下顺序实现，与里程碑对应。

1. 数据层：清单解析、图像读取与划分加载。
2. 矫正模块：四边形检测、顶点排序与透视变换。
3. 增强模块：直方图均衡与去阴影。
4. 传统基线：特征提取与分类器训练。
5. 深度模型：数据加载、训练与推理。
6. 评估模块：指标计算与实验编排。
7. 可视化模块：四角叠加图与并排图组。
8. 命令行入口：整合上述模块。
9. 隐私模块：候选检测、打码与审计（暂缓，决定 D-01；敏感样本按排除表处理，恢复条件见 OQ-10）。
