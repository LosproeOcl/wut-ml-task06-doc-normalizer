# 测试目录说明

本目录包含已实现的单元测试与集成测试。单元测试使用临时构造数据，集成测试校验真实清单、排除表、冻结划分与磁盘文件的一致性。

## 结构

```text
tests/
├── unit/          单元测试
└── integration/   集成测试
```

## 已覆盖范围

| 模块 | 测试重点 |
|---|---|
| 清单解析 | 必填字段、枚举取值、样本标识唯一性、排除表过滤 |
| 文件完整性 | `find_missing_files` 检出缺失文件 |
| 划分校验 | 分组互斥、清单哈希、样本到集合映射 |
| 图像读取 | 通道顺序、EXIF 方向、长边缩放、灰度与透明通道、中文路径、损坏文件 |
| 图像增强 | 通道保持、对比度提升、色彩保持、光照校正、确定性与参数校验 |
| 真实数据契约 | 344 样本、240/51/53 计数、哈希一致、文件齐全 |
| 网页接口（规划） | 健康检查、样本列表、上传分析、四角调整、非法输入 |

后续实现矫正、特征与指标模块时，按同一结构补充测试。

## 运行方式

```bash
pytest tests/unit -q
pytest tests/integration -q
pytest tests -q
```

单元测试不得依赖网络与真实数据集。集成测试依赖仓库内的 `data/manifests` 与 `data/splits`，不依赖图像内容，只校验路径存在性。

## 约定

1. 测试预期值使用手写字面量，不从被测代码推导。
2. 每个测试注明“破坏方式”，即删掉哪段实现会让该测试失败。
3. 修复缺陷须先补一个能复现缺陷的测试。
