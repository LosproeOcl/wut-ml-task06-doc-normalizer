# 测试目录说明

当前处于 M0 阶段，本目录仅保留结构说明，不包含测试代码。

## 计划结构

```text
tests/
├── unit/          单元测试
├── integration/   集成测试
└── fixtures/      测试用固定输入
```

## 测试范围

| 模块 | 测试重点 |
|---|---|
| 清单解析 | 必填字段校验、枚举取值、样本标识唯一性、分组一致性 |
| 顶点排序 | 横拍、竖拍、倒置与斜拍样本的排序结果 |
| 透视变换 | 输出尺寸、长宽比、顶点映射精度 |
| 特征提取 | 固定输入的输出维度与数值稳定性 |
| 指标计算 | 与手工计算结果一致，覆盖类别缺失情形 |
| 划分校验 | 同一分组键不跨集合 |

## 运行方式

```bash
pytest tests/unit -q
pytest tests/integration -q
```

单元测试不得依赖网络与真实数据集，应使用 `tests/fixtures/` 中的固定输入。集成测试可使用少量真实样本，须在测试说明中注明所需数据。
