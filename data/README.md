# 数据目录说明

本目录用于存放样本数据、清单与划分文件。图像二进制文件不纳入版本控制，原因见 `docs/adr/0005-数据集版本控制策略.md`。

## 目录职责

| 目录 | 内容 | 是否入库 |
|---|---|---|
| `raw_samples/` | 原始照片，按类别分子目录 | 仅目录结构与说明 |
| `release/` | 打码后的发布副本，用于对外材料 | 仅目录结构与说明 |
| `manifests/` | 样本清单，记录每张样本的元数据 | 是 |
| `annotations/` | 四角坐标等可选标注 | 标注文件入库，图像不入库 |
| `splits/` | 数据集划分文件 | 是 |

## 数据流向

```text
拍摄 → raw_samples/00_inbox → 类别判定与归档 → 清单登记 → 质量检查 → 划分冻结 → 实验使用
```

## 使用约定

1. 样本清单是唯一可信来源。任何统计、划分与报告数值均须以清单为依据。
2. 图像文件只在本地保存。克隆仓库后，目录为空属正常现象，须向数据负责人索取数据包。
3. 不得在 `raw_samples/` 下创建与类别无关的临时目录。
4. 新增类别须先修订 `docs/01-需求分析.md` 与 `docs/04-数据采集与标注规范.md`，再调整目录结构。
