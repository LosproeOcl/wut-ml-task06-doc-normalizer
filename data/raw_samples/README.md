# 原始样本目录

本目录用于存放组员上传的原始照片。图像文件不纳入版本控制。

## 上传流程

1. 拍摄完成后，将原始文件放入 `00_inbox/`。不要重命名，不要压缩，不要通过即时通讯软件传输。
2. 按 `docs/04-数据采集与标注规范.md` 判定类别，归档至四个类别目录之一。
3. 无法判定类别的样本放入 `99_unlabeled/`，并在组内说明理由。
4. 在 `data/manifests/sample_manifest.csv` 中登记样本信息。
5. 按质量检查清单逐项确认。
6. 若样本包含人脸、二维码或文档内个人信息，按 `docs/04` 第 10 节打码，发布副本写入 `data/release/`。

## 目录与类别对应

| 目录 | 类别代码 | 含义 | 目标数量 |
|---|---|---|---|
| `01_ppt_text/` | `ppt_text` | 投影幕布，纯文字 | 60（可上浮至 70） |
| `02_ppt_formula/` | `ppt_formula` | 投影幕布，含公式 | 60（可上浮至 70） |
| `03_paper_text/` | `paper_text` | 纸质或板书，纯文字 | 60（可上浮至 70） |
| `04_paper_formula/` | `paper_formula` | 纸质或板书，含公式 | 60（可上浮至 70） |
| `00_inbox/` | 无 | 待整理 | 无 |
| `99_unlabeled/` | 无 | 类别存疑 | 无 |

## 文件命名

```text
T06_P<组员编号>_<类别>_<场景>_<序号>.jpg
```

示例：`T06_P03_pptFormula_classroom_017.jpg`。完整规则见 `docs/04` 第 4 节。

## 注意事项

1. 单个文件不得超过 100 MB，常规手机照片不会触及该限制。
2. 图像文件被 `.gitignore` 排除，执行 `git status` 时不会显示，属预期行为。
3. 提交报告前，数据负责人须核对清单记录与实际文件是否一一对应。
