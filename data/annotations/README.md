# 标注目录说明

本目录存放除图像级类别之外的可选标注。图像级类别记录于 `data/manifests/sample_manifest.csv`。

## 四角坐标标注

文件为 `corners.json`，用于评估矫正精度。建议标注 60 张，覆盖四个类别与不同倾斜角度。

格式如下。

```json
{
  "T06_P01_pptText_classroom_001": [[x1, y1], [x2, y2], [x3, y3], [x4, y4]]
}
```

坐标顺序固定为左上、右上、右下、左下，单位为原图像素。

## 标注规则

1. 以文档内容的实际边界为准，不以纸张边缘或幕布边框为准。
2. 角点被遮挡时，按可见边的延长线估计交点，并在备注文件中说明。
3. 标注完成后由另一名组员抽查 10%，平均误差超过 5 像素时须重新标注。

## 备注文件

`corners_notes.md` 记录存疑样本，格式为样本标识加说明。
