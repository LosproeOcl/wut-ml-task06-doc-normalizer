# 数据划分目录说明

本目录存放数据集划分文件。划分文件纳入版本控制，以保证所有组员与所有实验使用同一划分。

## 文件命名

```text
split_v1.json
split_v2.json
```

版本号递增。已冻结的划分文件不得修改。确需调整时创建新版本，并重跑全部实验。

## 划分规则

1. 分组键为 `doc_page_id`。同一文档页的全部样本只进入一个集合。
2. 比例为训练集 70%、验证集 15%、测试集 15%。
3. 按类别与拍摄者分层，使分布接近。
4. 随机种子固定为 42。
5. 测试集须包含至少两名非主要拍摄者的样本。

## 文件结构

```json
{
  "version": "v1",
  "seed": 42,
  "group_key": "doc_page_id",
  "ratio": {"train": 0.7, "val": 0.15, "test": 0.15},
  "groups": {"train": [], "val": [], "test": []},
  "counts": {"train": 0, "val": 0, "test": 0},
  "frozen_at": "YYYY-MM-DD",
  "manifest_sha256": "清单文件哈希"
}
```

`manifest_sha256` 用于校验划分与清单是否对应。两者不一致时评估脚本须终止执行。

## 冻结流程

1. 数据负责人执行划分脚本。
2. 检查三类样本的类别分布与拍摄者分布。
3. 由评估负责人复核。
4. 填写 `frozen_at` 与 `manifest_sha256`，提交至仓库并告知全组。
