# 合成 PPT v3：严格 4:3 人工四角训练

| 项目 | 内容 |
|---|---|
| 日期 | 2026-11-28 |
| 背景 | 19 个自采 train PPT 人工四角，四边形实际宽高比与 4:3 相差 ≤0.05 |
| 样本 | 160 组（文字 80 / 公式 80），模板×类别各 20 |
| 定位 | 直接贴到 4:3 标注框，不外扩、不抖动 |
| 评估 | 5 折 × 3 种子，真实 PPT 验证折；测试集未使用 |
| 结论 | v3 **76.50% ± 6.85**，比基线 +6.06pp；定位更准、公式召回更高，但折均值低于 v2 |

## 2. 解释

1. **v3 的定位更可靠**：背景四角就是课件 4:3 区域，贴图不需要按整块幕布外扩；示例中不再出现 16:9 白边或旧页脚。
2. **v3 折均值低 1.75pp**：严格过滤后背景从 57 个降到 19 个，单背景重复约 8 次；v2 的背景多样性更高，fold2 尤其明显。
3. **v3 的 OOF 更高、公式召回更高**：OOF 78.05%、公式召回 81.0%，说明 4:3 定位让公式页更可分；但文字类 OOF 召回从 81.0% 降到 76.0%，是折均值下降的主因。
4. **稳定性**：v3 的种子/折标准差 6.85pp，低于 v2 的 7.92pp。
5. **候选集成**：把 v2 与 v3 的 3 种子概率平均后，OOF 准确率约 **80.0%**（探索性结果，尚未做独立验证/测试）。

## 3. 建议

- 如果**定位正确优先**：选 v3；它满足“只用 4:3 标注”的要求，公式召回最好。
- 如果**折均值优先**：v2 仍是当前最高（78.25%）。
- 若要上线：优先尝试 **v2+v3 六模型概率集成**，在真实验证集上复核后再决定；不要用测试集调参。
- 无论选哪版，测试集仍未使用，最终指标不能在这里报告。
