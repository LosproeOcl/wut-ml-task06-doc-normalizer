# MobileNetV3 验证记录

| 项目 | 内容 |
|---|---|
| 日期 | 2026-11-26 |
| 骨干 | MobileNetV3-Small，ImageNet 预训练 |
| 划分 | `split_v3`，训练 236、验证 51；测试集未参与任何训练或调参 |
| 最佳稳定验证结果 | 准确率 80.4%，宏平均 F1 79.0%–79.8%（`exp-cnn-05` / `exp-cnn-09` / `fusion-exp-01`） |
| 单次最高 | 准确率 84.3%（`exp-lstm-01`，种子敏感，见第 6 节） |
| 对照 | 传统基线 SVM 76.5%，宏平均 F1 75.7% |

> `exp-cnn-01`、`exp-cnn-02` 基于历史 `split_v2`，仅保留作预处理方向对照；当前结论以 `split_v3` 为准。

## 1. 实验设置

输入 224×224，ImageNet 归一化。训练集使用随机裁剪、旋转 5 度、轻微透视、亮度与对比度抖动；验证集使用中心裁剪。分类头两阶段训练：先冻结骨干训练分类头，再整体微调，早停耐心值 5。类别权重按训练集类别频次计算。

本轮实验固定 `rectify=true`、`enhance=false`、随机种子 42，最多 15 轮、冻结 3 轮，只改变训练集四角来源：

| 策略 | 含义 |
|---|---|
| `none` | 训练与验证都使用自动检测；失败时保留原图 |
| `always` | 训练集优先使用人工四角；验证集仍用自动检测 |
| `fallback` | 自动检测成功时用自动结果，失败时才回退人工四角；验证集仍用自动检测 |

人工四角共 236 条，覆盖全部训练集；验证与测试集不使用人工四角。

## 2. 结果

| 实验 | 划分 | 四角策略 | 轮数 | 准确率 | 宏平均 F1 | 混淆矩阵 |
|---|---|---|---:|---:|---:|---|
| `exp-cnn-01` | v2 | 自动 + 增强 | 12 | 66.7% | 59.1% | `[[28, 0], [17, 6]]` |
| `exp-cnn-02` | v2 | 自动，不增强 | 15 | 74.5% | 71.7% | `[[27, 1], [12, 11]]` |
| `exp-cnn-03` | v3 | `always` | 9 | 64.7% | 55.7% | `[[28, 0], [18, 5]]` |
| `exp-cnn-04` | v3 | `none` | 15 | 74.5% | 72.4% | `[[26, 2], [11, 12]]` |
| `exp-cnn-05` | v3 | `fallback` | 13 | **80.4%** | **79.0%** | `[[27, 1], [9, 14]]` |

与传统基线对比（同一 `split_v3`、同一验证集）：

| 方法 | 准确率 | 宏平均 F1 | 说明 |
|---|---:|---:|---|
| 传统特征 + SVM | 76.5% | 75.7% | 拉正 + 调参，无人工四角 |
| MobileNetV3-Small | **80.4%** | **79.0%** | 拉正，不增强，人工四角仅在自动失败时回退 |

## 3. 人工四角策略分析

| 策略 | 验证准确率 | 验证宏 F1 |
|---|---:|---:|
| `none` | 74.5% | 72.4% |
| `always` | 64.7% | 55.7% |
| `fallback` | **80.4%** | **79.0%** |

同策略的拉正统计（全部 340 张）显示，检测失败从 `none` 的 55 张降到 `always` / `fallback` 的 15 张；剩余失败均在验证与测试集，训练集 40 张失败样本由人工四角兜底。

McNemar 检验（51 张验证集）：

| 对比 | 仅前者正确 | 仅后者正确 | p 值 |
|---|---:|---:|---:|
| `fallback` vs `none` | 3 | 0 | 0.25 |
| `fallback` vs `always` | 9 | 1 | 0.021 |
| `fallback` vs 传统 SVM | 5 | 3 | 0.73 |

解释：

1. 把 236 张训练图全部换成人工作者紧贴文档边缘的裁切，会改变训练分布；验证仍按部署口径使用自动检测，模型在验证集上明显退化。
2. `fallback` 保留 196 张自动检测成功的训练图，仅对约 40 张自动失败的训练图使用人工四角，既修正了检测失败样本，又没有整体改变预处理分布。
3. 与传统 SVM 的差异在 51 张验证集上不显著；80.4% 是当前点估计，最终以测试集一次性评估为准。

## 4. 错误分析

`exp-cnn-05` 验证错误 10 张，其中公式页判为文字 9 张，文字页判为公式 1 张。公式类召回 14/23，文字类召回 27/28。

可能原因：

1. 224 像素输入压缩后，公式中的上下标与细笔画丢失。
2. 训练增强中的随机透视与旋转会破坏公式的符号结构。
3. 部分公式页实为文字与公式混排，标签边界模糊，与基线错例一致。
4. 验证集仅 51 张，单张样本影响约 2 个百分点。

## 5. 结论

1. 稳定最佳验证结果为 80.4%：`exp-cnn-05`（F1 79.0%）、`exp-cnn-09`（F1 79.8%）与 `fusion-exp-01`（F1 79.4%）准确率相同，均高于传统基线 76.5%。LSTM 单次 84.3% 的方差问题见第 6 节。
2. 人工四角不整体替代自动检测，只作为自动失败时的回退；该策略已设为训练脚本默认值 `--corners-policy fallback`。
3. `always` 与 `none` 保留用于复现和消融；正式报告使用 `fallback`，并说明人工四角覆盖 236 条、仅训练集、仅失败回退。
4. 测试集保持冻结，待方案确定后只评估一次。

## 6. 复合与序列模型补充

在固定 `split_v3`、自采数据、同一验证集上继续尝试：

| 模型 | 说明 | 准确率 | 宏 F1 |
|---|---|---:|---:|
| `exp-cnn-09` | MobileNetV3-Large，正则化 + 标签平滑 | 80.4% | 79.8% |
| `exp-cnn-ext-01` | 外部数据预训练后自采微调 | 76.5% | 74.2% |
| `fusion-exp-01` | 传统 1836 维 + CNN 576 维，融合 SVM | 80.4% | 79.4% |
| `exp-lstm-01` | CNN 特征图 + BiLSTM，默认种子 42 | **84.3%** | **84.3%** |
| `exp-lstm-02` | 同结构，正则化，种子 43 | 80.4% | 80.2% |
| `exp-lstm-03` | 同结构，种子 44 | 80.4% | 80.0% |
| `cv-lstm-01` | CNN+BiLSTM 5 折集成，验证集不参与早停 | 72.5% | 71.7% |
| `ensemble-cnn-lstm` | CNN 与 LSTM 概率平均，权重在验证集选择 | 86.3% | 86.2% |
| `ga-feature-01` | 遗传算法选择传统特征组，5 折 CV 适应度 | 74.5% | 74.4% |

解释：

1. `exp-lstm-01` 的 84.3% 是单次种子结果；换种子 43/44 都回到 80.4%，3 个种子概率平均也是 80.4%，5 折集成只有 72.5%。说明该序列头方差很大，不能据此宣称稳定达到 85%。
2. `ensemble-cnn-lstm` 的 86.3% 使用了在验证集上挑选的融合权重/路由阈值，属于验证集选择偏差，不能作为最终指标；固定种子平均后为 80.4%。
3. 遗传算法在训练集 5 折 CV 上达到 84.3%，但验证集只有 74.5%，是典型的特征选择过拟合。
4. 稳定可复现的最佳仍是 80.4% 左右：CNN fallback、CNN-Large 正则化、传统+CNN 特征融合三者准确率相同，宏 F1 在 79.0% 至 79.8% 之间；外部预训练反而降到 76.5%，不采用。
5. 51 张验证集上 80.4% 的 95% Wilson 区间约为 67.5%–89.0%，与 85% 并不冲突，但点估计不足以宣称达标。

## 7. 复现

```bash
# 当前最佳：自动检测优先，失败时回退人工四角
docker run --rm -v "$PWD:/app" -w /app docnorm:cpu-arm64 \
  env PYTHONPATH=/app/src python scripts/train_cnn.py \
  --exp-id exp-cnn-05 --epochs 15 --freeze-epochs 3 --no-enhance \
  --corners-policy fallback

# 消融：完全不使用人工四角
docker run --rm -v "$PWD:/app" -w /app docnorm:cpu-arm64 \
  env PYTHONPATH=/app/src python scripts/train_cnn.py \
  --exp-id exp-cnn-04 --epochs 15 --freeze-epochs 3 --no-enhance \
  --corners-policy none
```
