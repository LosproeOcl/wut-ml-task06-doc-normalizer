## 1. 处理流程

1. 光照校正：以灰度图的大尺度高斯背景为基准，按比例缩放各通道，削弱侧向阴影与光照不均。
2. CLAHE：在 LAB 色彩空间的亮度通道上执行限制对比度自适应直方图均衡，保持色相。
3. 去噪：双边滤波，降低均衡后放大的噪点。

所有步骤保持输入尺寸与通道数，输出为 uint8。

## 2. 单元测试

| 用例 | 验证内容 |
|---|---|
| 形状与类型 | 输出尺寸、通道数与 uint8 类型不变 |
| 局部对比度 | 低对比度文字页的灰度标准差上升超过 10% |
| 色彩保持 | 红色色块在均衡后仍以红色通道为主 |
| 灰度输入 | 灰度图返回二维数组 |
| 光照校正 | 梯度背景的标准差下降超过 25%，文字仍暗于背景 |
| 确定性 | 同一输入两次输出完全一致 |
| 参数校验 | 非正对比度限值、非法背景核被拒绝 |
| 开关 | 关闭光照校正时仍可完成均衡与输出 |

## 3. 真实样本耗时

| 指标 | 数值 |
|---|---|
| 样本数 | 20 张，四类各 5 张 |
| 中位耗时 | 13.5 ms |
| 95 分位耗时 | 50.5 ms |
| 灰度标准差比值中位数 | 0.92 |
| 平均亮度变化中位数 | +32 |

全局标准差在光照校正后可能下降，这是背景被拉平的正常结果，不能直接当作“对比度提升”。增强是否有效以 E4 的下游分类增益为准，报告中不单独以全局标准差下结论。

## 4. 已知限制

1. 镜面反光区域的信息已经丢失，本模块无法恢复，只做亮度均衡与局部对比增强。
2. 强阴影边界可能残留过渡带，必要时提高 `shadow_strength` 或增大 `shadow_kernel`。
3. 双边滤波在中央处理器上耗时随分辨率上升，1280 长边下仍在性能预算内。
