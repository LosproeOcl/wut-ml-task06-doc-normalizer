## 1. 判定规则

**公式为主（formula）**：页面核心学习目标是公式、推导或计算；满足任一条件：

1. 有至少 3 行独立显示的公式/推导，且公式占据页面主要阅读区域；
2. 页面以公式推导、证明、计算步骤为主体，文字只作解释；
3. 课堂幻灯片的核心内容是公式、定理或计算过程。

**文字为主（text）**：页面核心是叙述、列表、表格、示意图或代码；公式只作举例或符号说明，满足：

1. 正文/条目/表格/图示占主要阅读区域；
2. 公式为 0–2 个短行内联符号，不作为页面组织主线；
3. 代码页、英语词汇页、课程介绍页、流程说明页按文字处理。

**混合页**：按“如果只能保留一个标签，学生复习时更需要哪一类索引”判定；在 `audit_form.csv` 的备注中写明理由。不得用模型预测反向推断标签。
