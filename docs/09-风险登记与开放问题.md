## 3. 维护规则

1. 风险状态于每周例会更新，状态取值包括监控中、已缓解、已发生、已关闭、已接受。状态变更须注明依据与核对日期。
2. 开放问题形成结论后，须同步修订 `01-需求分析.md` 或 `06-评估与验收方案.md`，并将本表状态改为已确认。
3. 影响系统结构的结论须补充架构决策记录。
4. 合成数据（如 LaTeX 渲染公式页叠加拍摄畸变）属可选增强手段：启用前须经任课教师认可，仅可进入训练集，不得进入验证与测试集，并在报告中声明来源与数量。
