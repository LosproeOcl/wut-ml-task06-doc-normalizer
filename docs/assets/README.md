# 文档素材目录说明

本目录存放体积较小、须纳入版本控制的图像素材。

## 允许内容

1. 实地采数过程照片，用于证明数据来源。每位组员一至两张，命名格式为 `onsite_<姓名缩写>.jpg`。
2. 系统架构示意图、流程图等由文档生成的图。
3. 报告中使用的少量示意图。

## 禁止内容

1. 原始样本照片。原始样本存放于 `data/raw_samples/`，不纳入版本控制。
2. 模型权重与运行产物。
3. 含个人信息的图像。拍摄留证照片时不得出现正脸、姓名与学号。

## 体积要求

单幅图像不超过 2 MB。超出时须压缩至长边 1280 像素。压缩不得影响可辨识性。

## 引用方式

在文档中以相对路径引用，例如：

```markdown
![采数现场](assets/onsite_yyq.jpg)
```
