# 部署与访问

| 项目 | 内容 |
|---|---|
| 访问地址 | [https://ml-proj.losproeocl.cn](https://ml-proj.losproeocl.cn) |
| 认证 | Nginx Basic Auth，用户名 `t06`，口令 `admin`（公开演示口令） |
| 服务端口 | Server1 `127.0.0.1:54312`（Docker 容器 `t06-web`） |
| 部署方式 | 应用直接运行在 Server1 的 Docker 容器，Nginx 反向代理；不使用 SSH 反向隧道 |
| 公开模式 | `DOCNORM_PUBLIC_MODE=1`：隐藏并关闭训练集标注、四角与标注检查 |
| 文档版本 | v1.2，2026-11-29 改为 Server1 直接部署 |

## 1. 拓扑

```text
浏览器
  │ HTTPS + Basic Auth
  ▼
Server1 (149.104.21.193)
  │ Nginx: ml-proj.losproeocl.cn
  │ proxy_pass http://127.0.0.1:54312
  ▼
Docker 容器 t06-web
  │ docnorm:cpu-amd64
  ▼
FastAPI + 静态前端 + 处理链路
```

DNS 已解析：

```text
ml-proj.losproeocl.cn -> 149.104.21.193
```

旧的本机 SSH 反向隧道（`cn.losproeocl.mlproj-tunnel`）已停用；完整应用与模型均在 Server1 上运行。

## 2. Server1 部署

### 2.1 环境

| 项目 | 实测 |
|---|---|
| CPU | 2 vCPU，Intel Xeon Platinum 8259CL @ 2.5GHz |
| 内存 | 3.8 GB（另有 4 GB swap） |
| 磁盘 | 约 13 GB 可用 |
| 系统 | Ubuntu 22.04 x86_64 |
| Docker | 29.9.3 |

当前模型为 MobileNetV3-Small + OpenCV，CPU 推理常驻内存约 570 MB，2 vCPU 足够。

### 2.2 构建镜像

代码目录：`/opt/doc-normalizer`。

```bash
cd /opt/doc-normalizer
docker build --build-arg INSTALL_CJK_FONTS=0 \
  -f env/Dockerfile -t docnorm:cpu-amd64 .
```

### 2.3 启动容器

```bash
docker rm -f t06-web 2>/dev/null || true
docker run -d --name t06-web --restart unless-stopped \
  -p 127.0.0.1:54312:54312 \
  -v /opt/doc-normalizer:/app -w /app \
  -e PYTHONPATH=/app/src:/app \
  -e DOCNORM_PUBLIC_MODE=1 \
  docnorm:cpu-amd64 \
  uvicorn web.app:app --host 0.0.0.0 --port 54312
```

检查：

```bash
docker ps --filter name=t06-web
docker logs --tail 30 t06-web
curl -s http://127.0.0.1:54312/api/health
```

正常时 `/api/health` 返回：

- `routing_ready=true`：载体门控、PPT/纸质分支与 SVM 兜底就绪；
- `public_mode=true`；
- `annotation_enabled=false`。

### 2.4 更新代码

在本地仓库同步到服务器后重建并重启：

```bash
rsync -az --exclude='.git' --exclude='data/raw_samples' \
  /path/to/doc-normalizer/ server1:/opt/doc-normalizer/
ssh server1 'cd /opt/doc-normalizer && docker build --build-arg INSTALL_CJK_FONTS=0 -f env/Dockerfile -t docnorm:cpu-amd64 . && docker restart t06-web'
```

若只改了前端静态文件，可直接 `docker restart t06-web`（容器挂载了 `/opt/doc-normalizer`）。

## 3. 公开模式（服务器）

服务器以 `DOCNORM_PUBLIC_MODE=1` 运行，隐藏并关闭以下功能：

- 顶部导航：`训练集标签`、`训练集四角`、`标注检查`；
- 前端面板：`annotate-panel`、`corner-panel`、`review-panel`；
- 后端接口：`/api/samples`、`/api/annotations`、`/api/corners`、`/api/annotators`、`/api/review/*`，统一返回 404。

本机开发默认不设置该变量，标注功能仍可用；服务器部署不要省略 `-e DOCNORM_PUBLIC_MODE=1`。

## 4. Server1 Nginx

配置文件：

```text
/etc/nginx/sites-available/ml-proj
/etc/nginx/sites-enabled/ml-proj -> ../sites-available/ml-proj
```

要点：

1. HTTP 仅保留 ACME 验证路径，其余 301 到 HTTPS。
2. HTTPS 使用 Let's Encrypt 证书，路径 `/etc/letsencrypt/live/ml-proj.losproeocl.cn/`。
3. Basic Auth 文件 `/etc/nginx/.htpasswd-mlproj`，权限 `640 root:www-data`。
4. `client_max_body_size 20m`，与前端 15 MB 上传限制兼容。
5. `proxy_pass http://127.0.0.1:54312`，读写超时 300 秒。

证书续期由 Certbot 定时任务负责，可用 `certbot certificates` 查看到期时间。

## 5. 认证口令

演示口令为 `admin`（公开演示口令），用户名 `t06`。该口令按课程提交要求公开，仅用于短期答辩展示；答辩结束后如需长期对外，应轮换为随机口令并在 Server1 上增加来源 IP 限制。

数据集加密包口令不写入仓库，见随附《项目访问与数据集口令.txt》；该文件仅供任课教师查阅，不随仓库上传。

## 6. 故障排查

| 现象 | 检查 |
|---|---|
| 401 | 用户名是否 `t06`，口令是否为 `admin` |
| 502 | `docker ps` 看 `t06-web`；`curl http://127.0.0.1:54312/api/health` |
| 标注页/接口 404 | 服务器公开模式预期行为；本机开发不要设置 `DOCNORM_PUBLIC_MODE=1` |
| 容器启动失败 | `docker logs t06-web`；检查模型是否在 `/opt/doc-normalizer/runs/` |
| 证书错误 | `certbot certificates`；证书到期前自动续期 |
| 上传失败 | Nginx `client_max_body_size`、前端 15 MB 限制；单张解码后长边限制 2000 像素，超大图会先缩放 |
| 页面旧版本 | 容器是否挂载最新代码；`docker restart t06-web`，浏览器强制刷新 |
| 电脑与手机同一文件效果不同 | 电脑文件常保留 EXIF 方向，手机相册/相机入口可能已转码或转正；上传接口已按 EXIF 转正解码，仍不一致时对比分辨率、HEIC→JPEG 转码与压缩质量 |

## 7. 安全边界

1. 应用只监听 Server1 回环地址 `127.0.0.1:54312`，公网只经过 Nginx 443。
2. 所有公网请求经过 Basic Auth。
3. 原始数据集不部署到服务器；上传图片只写入临时结果目录，默认一小时过期。
4. 服务器公开模式关闭训练集标注、四角写入与标注检查接口，不暴露训练数据的标注工具。
5. 临时结果默认一小时过期，容器重启后清空。
6. GitHub Pages 只能托管静态文件，无法运行 FastAPI/模型，因此不用于完整 webapp。
7. 空间偏度优化：门控默认 TTA（-12/0/12 度平均）+ 阈值 0.3；可用 `DOCNORM_GATE_TTA=0`、`DOCNORM_GATE_THRESHOLD=0.5` 回退。
