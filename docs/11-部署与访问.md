# 部署与访问

| 项目 | 内容 |
|---|---|
| 访问地址 | [https://ml-proj.losproeocl.cn](https://ml-proj.losproeocl.cn) |
| 认证 | Nginx Basic Auth，用户名 `t06`，口令保存在本机密钥库 `t06-web-basic` |
| 本机端口 | `127.0.0.1:54312` |
| 反向隧道 | 本机 SSH 到 Server1，Server1 的 `127.0.0.1:54312` 转发到本机 54312 |
| 部署方式 | 应用不在 Server1 上运行，Server1 只做 Nginx 反向代理 |
| 文档版本 | v1.1，2026-11-27 增补网页操作与批量导出说明 |

## 1. 拓扑

```text
浏览器
  │ HTTPS + Basic Auth
  ▼
Server1 (149.104.21.193)
  │ Nginx: ml-proj.losproeocl.cn
  │ proxy_pass http://127.0.0.1:54312
  ▼
SSH 反向隧道（本机 → Server1）
  │
  ▼
本机 127.0.0.1:54312
  │ Docker 容器 t06-web
  ▼
FastAPI + 静态前端 + 处理链路
```

DNS 已解析：

```text
ml-proj.losproeocl.cn -> 149.104.21.193
```

## 2. 本机服务

```bash
cd /Volumes/DATA/courses/WUT/ML/repos/wut-ml-task06-doc-normalizer
docker run -d --name t06-web --restart unless-stopped \
  -p 127.0.0.1:54312:54312 \
  -v "$PWD:/app" -w /app \
  -e PYTHONPATH=/app/src:/app \
  docnorm:cpu-arm64 \
  uvicorn web.app:app --host 0.0.0.0 --port 54312
```

检查：

```bash
curl -s http://127.0.0.1:54312/api/health
```

`/api/health` 的 `routing` 字段报告门控、纸质集成与 PPT 模型路径；`routing_ready=true` 表示双分支可用。模型文件缺失时自动回退 SVM，网页仍可分析，但结果卡的分支显示为传统基线兜底。

容器设置了 `--restart unless-stopped`，Docker 启动后会自动恢复。当前镜像构建早于 Web 代码，因此通过挂载仓库运行；重建镜像后可去掉挂载。

### 2.1 网页操作

1. 上传：手机显示“拍照上传”与“从相册或文件选择”，电脑显示“拍照上传”与“从文件选择”；支持拖拽、多选，单张不超过 15 MB。
2. 队列：缩略图横向滑动；点击卡片切换结果；可逐张移除、清空队列，或用复选框、区间、全选选择导出范围。
3. 校准：自动检出成功时可直接拖动角点或整体框体；点击“应用四角”重新计算。手动四点需先应用一次，再继续微调。
4. 查看：点击矫正图或扫描件打开大图；结果面板显示载体（PPT/幕布或 A4 纸质稿）、分类分支（纸质稿 CNN 集成 / PPT CNN / 传统基线兜底）、分类概率、检测方式与耗时。
5. PDF：选择“导出当前单张”“导出选中”或“导出全部”；模式可选扫描件、矫正图或原图。
6. 标注：顶部“标注人”下拉框筛选个人队列；“标注检查”页可按成员与状态查看四角记录并退回重标。

静态文件带有版本查询参数（如 `app.js?v=...`）。更新前端后若浏览器仍显示旧版本，先强制刷新；必要时重启容器。

## 3. 反向隧道

本机 LaunchAgent：

```text
~/Library/LaunchAgents/cn.losproeocl.mlproj-tunnel.plist
```

它执行：

```bash
ssh -NT \
  -o ExitOnForwardFailure=yes \
  -o ServerAliveInterval=30 \
  -o ServerAliveCountMax=3 \
  -R 127.0.0.1:54312:127.0.0.1:54312 \
  root@149.104.21.193
```

检查：

```bash
ssh root@149.104.21.193 'ss -lntp | grep 54312'
```

重启隧道：

```bash
launchctl kickstart -k gui/$(id -u)/cn.losproeocl.mlproj-tunnel
```

## 4. Server1 Nginx

配置文件：

```text
/etc/nginx/sites-available/ml-proj
/etc/nginx/sites-enabled/ml-proj -> ../sites-available/ml-proj
```

要点：

1. HTTP 仅保留 ACME 验证路径，其余 301 到 HTTPS。
2. HTTPS 使用 Let's Encrypt 证书，路径 `/etc/letsencrypt/live/ml-proj.losproeocl.cn/`。
3. Basic Auth 文件 `/etc/nginx/.htpasswd-mlproj`，权限 `640 root:www-data`。
4. `client_max_body_size 20m`，与前端 15 MB 上传限制兼容。
5. `proxy_pass http://127.0.0.1:54312`，读写超时 300 秒。

证书续期由 Certbot 定时任务负责，可用 `certbot certificates` 查看到期时间。

## 5. 认证口令

口令不在本文档中。取用方式：

```bash
node ~/.pi/agent/skills/locallab/scripts/secretgate.mjs run \
  --name t06-web-basic -- sh -c 'printf "%s" "$SECRET"'
```

只在本机终端查看，不要写入仓库、群公告或截图。组员需要访问时，由项目负责人单独告知。

当前使用用户指定的课程演示弱口令，仅限短期展示。答辩结束或对外长期发布前必须轮换为至少 16 位随机口令；若继续使用弱口令，建议在 Server1 上增加来源 IP 限制。

## 6. 故障排查

| 现象 | 检查 |
|---|---|
| 401 | 用户名是否 `t06`，口令是否来自 `t06-web-basic` |
| 502 | 本机容器是否运行；Server1 的 54312 是否有 sshd 监听 |
| 隧道断开 | `launchctl print gui/$(id -u)/cn.losproeocl.mlproj-tunnel` |
| 证书错误 | `certbot certificates`；证书到期前自动续期 |
| 上传失败 | Nginx `client_max_body_size`、前端 15 MB 限制；单张解码后长边限制 2000 像素，超大图会先缩放 |
| 页面旧版本 | 容器是否挂载了最新仓库；必要时 `docker restart t06-web` |
| 电脑与手机同一文件效果不同 | 电脑文件常保留 EXIF 方向，手机相册/相机入口可能已转码或转正；上传接口已按 EXIF 转正解码，仍不一致时对比分辨率、HEIC→JPEG 转码与压缩质量 |

## 7. 安全边界

1. 原始图像只在本机，Server1 不保存数据。
2. 所有公网请求经过 Basic Auth。
3. 应用只监听本机回环地址，Server1 通过 SSH 隧道访问，不直接暴露 54312。
4. 标注接口只允许训练集，服务端校验分配人。
5. 临时结果默认一小时过期，容器重启后清空。
6. GitHub Pages 只能托管静态文件，无法运行 FastAPI/模型，因此不用于完整 webapp；完整演示仍走本机 + Server1 反向代理。
7. 空间偏度优化：门控默认 TTA（-12/0/12 度平均）+ 阈值 0.3；可用 `DOCNORM_GATE_TTA=0`、`DOCNORM_GATE_THRESHOLD=0.5` 回退。
