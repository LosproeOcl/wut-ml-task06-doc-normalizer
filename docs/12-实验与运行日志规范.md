# 实验与运行日志规范

| 版本 | v1.1，2026-11-27 增补载体门控、纸质模型与零样本评估 |
|---|---|

每个模型版本必须留下可复现的参数、环境与产物记录。新实验统一使用 `RunLogger`，不再只保存一个 `metrics.json`。

## 1. 目录结构

```text
runs/<exp_id>/
├── run.json          # 完整参数、环境、数据哈希、指标、产物清单
├── train.log         # 训练过程 stdout/stderr（含异常栈）
├── epochs.csv        # 逐轮 loss / 指标 / 学习率 / 梯度范数
├── metrics.json      # 与旧报告兼容的指标
├── config.snapshot.yaml
├── cnn.pt / svm.joblib / lstm.pt
└── predictions_val*.csv
```

`runs/` 不进入版本控制；需要长期保留的汇总写入 `reports/run_index.csv`。

## 2. run.json 字段

| 字段 | 内容 |
|---|---|
| `exp_id` / `script` / `status` | 实验标识、入口脚本、completed / failed / interrupted |
| `started_at` / `finished_at` / `duration_seconds` | 运行时间 |
| `argv` / `args` | 完整命令行与解析后的参数（含默认值） |
| `config` | 实际使用的完整配置 |
| `environment` | Python、平台、CPU、torch、sklearn、OpenCV、Pillow 版本 |
| `git` | commit、分支、未提交文件数 |
| `files` | 配置、清单、划分、标注文件的字节数与 SHA-256 |
| `metrics` | 最终验证指标 |
| `extra` | 数据集规模、类别权重、训练历史等 |
| `artifacts` | 产出文件相对路径与大小 |

`epochs.csv` 字段：`epoch, timestamp, elapsed_seconds, train_loss, val_loss, val_accuracy, val_iou, lr, grad_norm, param_norm`。分类任务用 `val_accuracy`，屏幕检测用 `val_iou`；`lr`、`grad_norm`、`param_norm` 由训练循环逐轮记录，用于绘制学习率、梯度与损失诊断图。

## 3. 使用方式

```python
from docnorm.utils.runlog import RunLogger

logger = RunLogger(
    exp_id, out_dir, "scripts/train_cnn.py", args, config, root=ROOT
)
# CNN 训练时逐轮记录
history = classifier.fit(..., on_epoch=logger.log_epoch)
logger.finish(metrics=metrics, extra={"epochs": len(history["train_loss"])})
```

异常时调用 `logger.fail(exc)`，或在进程退出时由 `atexit` 标记为 `interrupted`。`train.log` 会保留异常栈。

## 4. 汇总索引

```bash
python3 scripts/index_runs.py
```

生成 `reports/run_index.csv`。优先读取 `run.json`；历史实验没有 `run.json` 时从 `metrics.json` 回填，缺失字段留空，并标记 `log_status=metrics only` 与“历史实验，参数按报告回填”。

旧实验（`exp-cnn-01` 至 `exp-cnn-09`、`exp-20261126-01` 至 `08` 等）由 `scripts/backfill_runlogs.py` 生成带 `backfilled: true` 的 `run.json`；无法确认的参数留空，不伪造环境与逐轮日志。`reports/run_index.csv` 中这类记录标记为 `run.json (backfilled)`。

当前 `RunLogger` 跟踪的外部数据与辅助训练清单包括 `external_aux.csv`、`external_aux_small.csv`、`scb_screen.csv`、`screen_gate.csv`、`carrier_gate.csv`、`paper_content.csv` 与 `paper_content_extctl.csv`。清单变更会使 run.json 的 `files` 哈希变化，便于判断实验是否可复现。

零样本评估脚本 `scripts/eval_pretrained_on_self.py` 不训练模型，因此不写 run.json；结果写入 `reports/pretrained_zero_shot.json`，逐样本预测写入对应 `runs/pretrain-external-*/predictions_self_*.csv`。
