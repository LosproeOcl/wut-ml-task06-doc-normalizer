# ADR-0011：训练集人工标签单独存放，不修改冻结清单与划分

- 状态：已接受
- 日期：2026 年 11 月 26 日
- 决策人：余青阳、张艺萧、李念
- 相关文档：`01-需求分析.md` FR-25、FR-26，`03-架构设计.md` 第 13 节，`04-数据采集与标注规范.md` 第 9 节

## 背景

前端需要支持一定程度的人工标注，用于修正训练集中的错误标签或补标存疑样本。样本清单 `sample_manifest.csv` 已冻结并与 `split_v3` 的哈希绑定，直接修改清单会导致划分哈希失效，进而影响所有实验的可比性。

课程要求提交材料不含个人信息，标注界面只能使用已清洗、已排除敏感样本后的数据集。

## 备选方案

| 方案 | 影响 | 风险 |
|---|---|---|
| 直接修改清单中的 label | 立即生效 | 清单哈希变化，冻结划分失效，历史实验不可复现 |
| 修改划分文件 | 可调整标签 | 破坏分组互斥与测试集冻结规则 |
| 独立标注文件，训练时合并 | 不动清单与划分 | 需要训练脚本支持合并，标注来源需审计 |

## 决策

1. 人工标签写入 `data/annotations/manual_labels.csv`，字段为 `sample_id,label,annotator,updated_at`。
2. 只允许训练集样本写入。验证集与测试集标签不得修改；服务端按 `split_v3` 的分组归属校验。
3. 标签取值为 `text` 或 `formula`，与内容二分类口径一致。
4. 训练脚本在构建数据时读取该文件，仅对训练集样本应用覆盖，并在日志中报告覆盖条数。验证与测试始终使用清单原标签。
5. 标注文件纳入版本控制，便于审计与复现；图像不纳入版本控制。
6. 前端提供逐张标注、当前标签显示、已标注数量统计与跳过操作。

## 理由

1. 保持清单与划分不变，历史实验结果仍可复现。
2. 标注变更可追溯，出现争议时能定位到操作者与时间。
3. 只允许训练集覆盖，避免通过修改验证/测试标签虚高指标。
4. 文件为纯文本，体积小，适合版本控制。

## 后果

1. 新增 `ManualLabelStore` 与网页标注接口。
2. `train_classic.py` 与 `train_cnn.py` 增加覆盖合并逻辑，默认读取该文件。
3. 标注后需重新训练模型，旧模型不自动更新。
4. 报告中若使用人工标注，须说明标注来源、数量与仅作用于训练集。
5. 该文件不替代原始清单，两者不一致时以清单为原始标签、以标注文件为训练覆盖。
