# ADR-0012：训练集四角覆盖采用扫描式拖拽标注并独立存储

- 状态：已接受
- 日期：2026 年 11 月 26 日
- 决策人：余青阳、任万东、李念
- 相关文档：`01-需求分析.md` FR-27、FR-28，`03-架构设计.md` 第 13 节，`04-数据采集与标注规范.md` 第 9 节
- 关联：ADR-0009（取消评估用人工角点金标准）、ADR-0011（训练集标签覆盖）
- 修订：第 4 条由 ADR-0015 修订为“自动检测失败时才回退人工四角”（2026-11-26）

## 背景

自动检测在 160 张实测中检出率为 82%，未检出与低置信样本需要人工修正。仅靠文本标签校正不能解决拉正失败的问题，需要提供类似扫描仪应用的交互：显示原图、给出自动四角作为初始建议、拖拽四个控制点、确认后回写。

该标注属于训练与演示阶段的运行覆盖，不是评估用金标准。若把它当作测试集的角点真值，会与 ADR-0009 的结论冲突，并引入“用检测器初始化、再人工微调”的偏差。

## 决策

1. 新增 `data/annotations/manual_corners.csv`，字段为 `sample_id,points,annotator,updated_at`，`points` 为四个顶点的 JSON 数组。
2. 只允许训练集样本写入；服务端按 `split_v3` 的分组归属校验，验证集与测试集拒绝写入。
3. 网页“训练集四角”页调用检测器生成初始四角；用户拖拽或点击四个顶点后，点击“确认四角”回写。
4. 训练脚本在 `rectify` 开启时优先使用已保存四角，没有记录时回退到自动检测；覆盖仅作用于训练集。
5. 该文件不进入评估指标计算，不作为角点误差的真值。评估仍按 ADR-0009，以自动检出率与下游分类增益为准。
6. 图像不写入标注文件，仅记录样本标识与坐标。

## 理由

1. 扫描式交互符合用户对“拖四个角”的直觉，比输入坐标更低成本。
2. 自动检测作为初始建议可以显著减少拖动距离；确认动作保留人工最终决定权。
3. 独立文件避免修改冻结清单与划分，保持历史实验可复现。
4. 仅训练集覆盖，避免通过修改验证/测试数据虚高指标。
5. 与 ADR-0011 的标签覆盖使用同一原则：原始清单为准，覆盖文件为训练输入。

## 后果

1. 网页新增 `/api/corners` 查询与保存接口，以及训练集四角页。
2. 训练脚本日志报告人工四角覆盖条数。
3. 四角覆盖只影响拉正结果，不改变标签与划分。
4. 报告中若使用人工四角，须说明数量、仅训练集、以及自动检出率的基线。
