# ADR-0017：网页主链路接入载体门控与双分支分类

- 状态：已接受
- 日期：2026 年 11 月 27 日
- 决策人：余青阳、蒋翔恒、李念
- 相关文档：`docs/03-架构设计.md` 第 5.5、13 节，`reports/web_integration.md`
- 关联：ADR-0016

## 背景

`carrier-gate-01` 在自采验证 51 张上全对，纸质稿三分支集成与 PPT CNN 分别完成训练。网页此前只加载验证集表现最好的 SVM，无法利用载体先验，也无法在纸质稿与 PPT 上使用不同分支。

## 决策

1. 网页分析主链路改为：

```text
原图 → 载体门控（screen / other）
      ├─ paper → 纸质稿 CNN 集成（extctl-01/43/44 概率平均）
      ├─ ppt   → PPT CNN（exp-cnn-05）
      └─ 任一门控或分支模型缺失 → 传统 SVM 兜底
```

2. 门控输入使用上传原图（与训练分布一致），内容分类输入使用拉正后的图像。
3. 响应新增 `carrier`、`carrier_probabilities`、`branch` 字段；网页以徽标显示“载体 / 分支”。
4. `/api/health` 新增 `routing`，报告门控、纸质分支与 PPT 分支的模型路径及 `routing_ready`。
5. 模型路径支持环境变量覆盖：`DOCNORM_CARRIER_GATE`、`DOCNORM_PAPER_MODELS`（`os.pathsep` 分隔）、`DOCNORM_PPT_MODEL`。
6. 模型缺失时不得阻断分析；自动回退 SVM，并在 `branch` 中保留兜底标记。

## 结果

自采验证集 51 张逐页评估：

| 指标 | 数值 |
|---|---:|
| 准确率 | 88.24% |
| 宏平均 F1 | 88.01% |
| PPT 分支准确率 | 95.24%（20/21） |
| 纸质分支准确率 | 83.33%（25/30） |
| 分支样本数 | paper 30 / ppt 21 |
| 混淆矩阵 | `[[26, 2], [4, 19]]` |

作为对照，单模型 CNN 为 80.39% / 79.03%。路由链路在验证集上多对 4 张；测试集尚未评估。

## 理由

1. 门控在验证集上把 30 张纸质稿与 21 张 PPT 全部分对，分支选择没有额外错误。
2. 纸质稿分支使用 3 个种子的概率平均，比单种子更稳定；PPT 分支使用现有最佳 CNN。
3. 保留 SVM 兜底，保证模型文件缺失、加载失败或新环境首次启动时网页仍可分析。
4. 输出载体与分支字段，便于演示时解释“为什么这个页面走这条模型”。

## 后果

1. 网页首次分析会加载门控 + 3 个纸质模型 + 1 个 PPT 模型，冷启动约数秒；之后使用进程内缓存。
2. 模型权重仍在 `runs/`（不纳入版本控制），部署时必须挂载带权重的仓库目录；缺失时自动回退。
3. `docs/03`、`docs/11`、`web/README`、`README` 与评估报告需同步双分支说明与指标。
4. 门控与分支均在 51/30 张小验证集上评估；测试集保持冻结，最终指标以测试集为准。
5. 纸质分支的增益与类别权重相关（见 `reports/external_control.md`），本 ADR 只决定“接入”，不宣称数据来源本身更优。
