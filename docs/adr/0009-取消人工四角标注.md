# ADR-0009：取消离线人工四角标注，改用自动参考与交互兜底

- 状态：已接受
- 日期：2026 年 11 月 26 日
- 决策人：余青阳、任万东、张艺萧
- 相关文档：`01-需求分析.md` FR-02、`04-数据采集与标注规范.md` 第 9 节、`06-评估与验收方案.md`
- 取代：`04` 原“标注 40 张四角作为 gold”的安排

## 背景

原计划标注 40 张样本的四个角点，用于计算角点误差并评测矫正精度。该安排有三个问题。

1. 人工成本高。逐点标注 40 张需要约两小时，且需要第二人抽查，在两周工期内占用关键路径。
2. 与课程指标关联弱。课程评分关注内容分类准确率与对比实验，角点像素误差不是必交指标。
3. 标注结果只服务评测，不进入训练。当前检测器为传统算法，不需要角点训练数据。

## 备选方案

| 方案 | 人工成本 | 评估有效性 | 依赖 | 结论 |
|---|---|---|---|---|
| 人工标注 40 张作为金标准 | 高 | 高 | 无 | 不采用 |
| 用本项目检测器输出作为参考 | 无 | 无，属于循环论证 | 无 | 不可用于评估 |
| 用独立模型 DocAligner 预测作为参考 | 无 | 中等，存在域差距 | ONNX 模型 | 可选 |
| 不设几何金标准，评估自动化率与下游增益 | 无 | 高，直接对应课程指标 | 无 | 采用 |

## 决策

1. 取消离线人工四角标注工序，不再维护 `corners.json` 金标准。
2. 检测环节的主要指标改为自动检出率与稳定性，目标为合规样本不低于 80%。
3. 矫正质量通过下游效果评估：同一分类模型在原始图、矫正图、矫正增强图上的准确率对比；辅以人工目视抽查六至八张，评估不依赖角点文件。
4. 演示时的交互调整只服务当前会话。训练集可保存四角覆盖用于训练拉正，规则见 ADR-0012；该覆盖不进入验证/测试，也不作为评估金标准。
5. 若报告需要角点像素误差，使用 DocAligner 的独立预测作为参考，并明确标注为“模型参考值”，不得表述为人工真值。

## 理由

1. 课程要求的是内容分类准确率、传统与深度学习的对比、可视化结果。矫正环节的价值应通过下游分类增益体现，而不是孤立的角点误差。
2. 评估链路不依赖人工角点，任何组员可在容器内复现；训练集可选四角覆盖只影响训练输入。
3. 交互式四角调整同时解决“检测失败如何继续演示”的问题，比离线标注更符合演示场景。
4. 避免用检测器输出评估检测器，保证结论有效。

## 后果

1. `04` 第 9 节说明“评估无离线金标准”，同时允许训练集四角覆盖，见 ADR-0012。
2. `06` 删除角点误差金标准指标，实验 E1 改为自动化率与稳定性统计；新增下游增益对比。
3. 前端必须提供四角拖拽与重新矫正能力，该能力由 ADR-0010 的前端方案承接。
4. 报告中不得出现“角点误差基于人工标注”的表述，除非后续另行完成标注。
