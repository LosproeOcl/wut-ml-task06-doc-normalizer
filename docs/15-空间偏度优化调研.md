# 空间偏度优化调研

| 项目 | 内容 |
|---|---|
| 日期 | 2026-11-27 |
| 问题 | 正面 PPT/幕布识别较准，存在空间偏度的图像不及预期 |
| 约束 | 暂不新增样本；只用现有自采验证集与合成偏度压力测试 |
| 结论 | 主要瓶颈在载体门控，不在内容模型；门控 TTA + 0.3 阈值已启用，待真实偏度样本复核 |
| 相关图 | `reports/figures/spatial_skew_accuracy.png`、`spatial_skew_gate.png`、`spatial_skew_examples.png` |

## 1. 问题表现

`docs/record-img/` 中新增了三张过程截图：

- `测试识别 PPT-text1-正面.png`、`测试识别 PPT-text2-正面.png`：正面样张；
- `测试识别 PPT-text3-偏度-不达预期.png`：偏度样张，四角框与矫正/扫描结果仍保留明显倾斜或屏幕边框。

这些截图说明问题不只出现在内容分类，也可能出现在四角定位、载体门控与扫描件生成环节。截图中人物已做像素化脱敏。

## 2. 现有链路

```text
原图 → 载体门控（PPT/幕布 vs A4 纸质稿）
      ├─ PPT   → exp-cnn-05 内容模型
      ├─ paper → 纸质稿 CNN 集成
      └─ 模型缺失 → SVM 兜底
```

偏度可能影响三个环节：

1. 载体门控把倾斜幕布判成纸质稿，走错分支；
2. 自动四角检测失败或框到屏幕外框，拉正后仍残留透视；
3. 内容模型对残余偏度不鲁棒。

## 3. 无新增样本的实验设计

自采验证集只有 21 张 PPT 页，且 `angle_deg` 大多为 10°，缺少大角度真实样本。因此用**合成梯形透视**做压力测试：

- 对 21 张 PPT 验证页分别施加 0°/10°/20°/30°/40° 梯形透视；
- 交替使用上下边/左右边收敛，模拟不同方向的相机倾斜；
- 不参与训练，仅用于评估；
- 同时评估“内容模型”和“完整链路”两条路径。

脚本：`scripts/eval_spatial_skew.py`、`scripts/eval_gate_skew.py`。

## 4. 结果

### 4.1 内容模型与完整链路

| 合成偏度 | 内容模型（拉正后加偏度） | 完整链路（原门控 0.5） |
|---:|---:|---:|
| 0° | 90.5% | 90.5% |
| 10° | 85.7% | 90.5% |
| 20° | 85.7% | 85.7% |
| 30° | 85.7% | **71.4%** |
| 40° | 81.0% | **71.4%** |

内容模型在 30°/40° 仍有 85.7%/81.0%，而完整链路掉到 71.4%。说明主要损失来自门控/路由，而不是内容模型本身。

### 4.2 门控 PPT 召回

| 合成偏度 | 原门控 @0.5 | 原门控 TTA @0.3 | 偏度增广门控 TTA @0.2 |
|---:|---:|---:|---:|
| 0° | 100% | 100% | 100% |
| 10° | 95.2% | 100% | 100% |
| 20° | 100% | 100% | 100% |
| 30° | 76.2% | 90.5% | 90.5% |
| 40° | 38.1% | 61.9% | **76.2%** |

纸质稿召回在所有阈值/角度下保持 100%，说明在当前验证集上降低阈值没有引入纸质误判。偏度越大，门控越倾向把 PPT 判成纸质稿。

### 4.3 门控 TTA + 阈值 0.3 的完整链路

| 合成偏度 | 原链路 | 门控 TTA + 0.3 |
|---:|---:|---:|
| 0° | 90.5% | 90.5% |
| 10° | 90.5% | 85.7% |
| 20° | 85.7% | 85.7% |
| 30° | 71.4% | **81.0%** |
| 40° | 71.4% | **81.0%** |

五个角度的平均准确率从 **81.9%** 提升到 **84.8%**（+2.9 个百分点）。代价是 10° 时有一张样张被强制走 PPT 分支，失去纸质分支的纠错；30°/40° 各多对 2 张。

### 4.4 其他尝试

- **内容模型旋转 TTA**：对内容模型有局部提升，但完整链路仍受门控限制；标签修正后未作为主方案。
- **偏度增广门控**：`carrier-gate-skew-01` 外部验证 100%，30°/40° 门控 PPT 召回提升到 90.5%/76.2%；完整链路与“原门控 + TTA + 0.3”相同，暂未显示额外收益。
- **内容模型偏度增广**：`exp-cnn-skew-01` 在旧标签验证集只有 70.6%（对照 80.4%），**不采用**；强透视增强明显伤害正常样本。该结论在标签修正后未复测，但方向为负。
- **标签修正后重训**：`exp-cnn-corrected-01` 验证集 72.6%，低于旧模型；纸质稿修正标签重训 76.7%/73.3%/70.0%，旧集成在修正标签上仍有 80.0%。因此网页暂不替换模型，待样本补足后重训。
- **新增 93 张 PPT 样本增训**：`00_inbox` 人工分为 36 张 `ppt_formula` / 57 张 `ppt_text`，按同一幻灯片聚合为 48 组、每组保留一张代表，只加入训练集生成 `split_v4`（329/51/53）。全量重训 `exp-cnn-inbox-01` 为 74.5%（PPT 16/21）；从旧模型微调 `exp-cnn-inbox-ft-01` 为 80.39%（PPT 17/21）；PPT 专用去重模型 `exp-cnn-ppt-dedup-01` 为 PPT 18/21（85.7%，旧模型 19/21）。新样本提升了纸质验证，但 PPT 文本页仍有 3 张误判，暂不替换网页 PPT 模型。

## 5. 判断

1. **内容模型不是主要短板**：残余偏度下仍有 85%–90%；当前 webapp 的明显下降主要来自门控误路由。
2. **门控阈值/TTA 是成本最低的无样本优化**：0.3 阈值 + 旋转 TTA 在合成偏度下把 30°/40° 从 71.4% 提到 81.0%，纸质召回未降。
3. **偏度增广门控可作为候选**：对 40° 门控召回更好，但完整链路尚未超过阈值/TTA 方案，需真实样本验证。
4. **内容强增广不可取**：正常验证集掉 10 个百分点，说明不能用合成强透视替代真实偏度数据。
5. **四角/扫描件仍需改进**：截图显示偏度样张的扫描件仍带屏幕边框或残余倾斜；screen bbox 是轴对齐矩形，不能解决透视，需边缘/消失点或更稳的四角检测。

## 6. 建议

### 已实施（不新增样本）

- 网页门控已启用 `web.gate_tta=true` + `web.gate_threshold=0.3`（ADR-0018），环境变量 `DOCNORM_GATE_TTA=0` / `DOCNORM_GATE_THRESHOLD=0.5` 可回退。
- 门控 TTA 为原图 -12°/0°/12° 旋转概率平均；只影响分支选择。
- 保留 `carrier-gate-skew-01` 作为候选，不替换门控主模型。
- 内容模型强偏度增广不采用；当前证据为负。
- 真实样本到位后做阈值校准，不在测试集上调参。

### 待真实偏度样本到位后

1. 按 `angle_deg` 分桶（10° 以下 / 10–20° / 20–30° / 30° 以上）报告门控与内容准确率；
2. 在真实样本上复测 0.3/0.4/0.5 阈值与 TTA；
3. 对比“原门控”和“偏度增广门控”，以完整链路准确率为准；
4. 单独评估四角检测成功率与扫描件质量，不要只看分类标签；
5. 测试集保持冻结，不用偏度样本反复调参。

## 8. 边界

- 合成梯形透视是压力测试，不等于真实投影幕布的光照、反光、屏幕边框与拍摄距离；
- 验证集只有 21 张 PPT 页，单张影响约 4.8 个百分点；
- 测试集未参与；
- 0.3 阈值/TTA 已在网页默认启用，但尚未用真实偏度样本复核；如有正面样本回退，可用环境变量回退；
- 本调研未替换门控/内容模型权重；
- 真实偏度样本到位后需重新评估，不能仅凭本报告长期定稿；
- **数据一致性提醒**：调研时 `check_dataset.py` 报告 11 个清单路径缺失、11 个未登记文件，原因为人工复核后修正公式/文字归档位置（例如 `IMG_6174` 从 `01_ppt_text` 移到 `02_ppt_formula`）。2026-11-27 已用 `scripts/reconcile_manifest_paths.py` 同步 `file`/`label` 并重算清单哈希；分组归属与计数未变。四个分组仍含多页混合标签（`AF-035`、`AT-040`、`PT-016`、`PT-N006`），已作为警告保留，需人工确认是否拆组。此前基于旧标签的指标需重跑后再比较。
- **2026-11-27 新增样本**：`00_inbox` 的 93 张 PPT 幕布照片已人工分为 36 张 `ppt_formula` / 57 张 `ppt_text`，只加入训练集，`split_v4` 为 329/51/53；val/test 未变，偏度压力测试仍用原 21 张 PPT 验证页。新增样本用于内容模型增训，不改变本报告的评估口径。2026-11-27 晚又补 9 张目标检测章节实拍（2 张幻灯片多角度），`split_v4` 计数更新为 338/51/53；本报告的压力测试仍使用原 21 张 PPT 验证页。
