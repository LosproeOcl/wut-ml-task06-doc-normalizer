## 文档编写约定

本仓库文档遵循以下约定，以降低歧义并便于交叉引用。

1. 需求编号统一为 `FR-xx`、`NFR-xx`、`DR-xx` 三种前缀。跨文档引用须同时给出编号与文档名。
2. 尚未确定的事项一律登记在 `09-风险登记与开放问题.md`，编号为 `OQ-xx`。正文中不得出现未登记的待定表述。
3. 指标口径以 `06-评估与验收方案.md` 为唯一依据。其他文档引用指标时只写编号或结论，不重复定义计算方式。
4. 设计变更须同步更新对应文档；影响架构的变更须新增或修订架构决策记录。
5. 术语首次出现时给出定义，后续保持同一表述。主要术语见 `01-需求分析.md` 第 2 节。
