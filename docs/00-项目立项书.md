## 1. 项目背景

课堂场景中存在大量斜拍文档。学生常以手机拍摄投影幕布上的幻灯片、黑板上的板书或桌面上的纸质笔记。此类图像普遍存在三项缺陷。

第一项是几何畸变。拍摄时相机光轴与文档平面不垂直，文档在画面中呈梯形，文字行倾斜，无法直接阅读或归档。

第二项是光照缺陷。投影幕布与电子屏易产生镜面反光，台灯或窗户形成侧向阴影，导致局部区域对比度显著下降。

第三项是内容异构。同一批照片中公式页与纯文字页混排，人工分类耗时且容易出错。

本项目将上述三项缺陷拆分为一条可评估的处理链路，依次完成定位、拉正、增强与归类，并以传统机器学习与轻量深度学习两条技术路线进行对照，形成可复现的量化结论。

## 2. 项目目标

### 2.1 业务目标

1. 实现一套可在普通笔记本中央处理器上离线运行的文档矫正与归类原型。
2. 输出可直接用于实验报告与课堂汇报的对比图组，内容包括原图、四角标注、矫正增强结果与类别标签。
3. 形成可复现的实验记录。任何组员更换设备后，按文档步骤均能复现同一组指标。

### 2.2 技术目标

| 编号 | 目标 | 判定方式 |
|---|---|---|
| G-01 | 内容二分类（文字/公式）测试集准确率不低于 85% | 独立测试集，按文档页分组划分 |
| G-02 | 拉正后的分类准确率高于拉正前 | 同一模型、同一测试集，配对比较 |
| G-03 | 轻量深度学习不劣于传统基线，且在公式类上更优 | 同一划分下的宏平均 F1 对比 |
| G-04 | 合规样本上的自动检出率不低于 80%，未检出样本在交互界面调整或跳过 | 以自动检出率与下游分类增益评估，不设人工角点金标准 |
| G-05 | 中央处理器单图端到端耗时不超过 1.0 秒 | 统一容器环境中测量，不含模型首次加载 |
| G-06 | 对外使用的图像不含可识别个人信息（数据清洗已完成） | 对外材料仅引用无个人信息样本，排除表覆盖全部敏感样本 |
| G-07 | 网页演示可完成上传、四阶段展示与四角调整，端到端不超过 3 秒 | 中央处理器环境，1280 像素长边，分类模型为传统基线 |

准确率不低于 85% 为课程建议指标。其余六项为本组自设的过程质量指标，用于判断中间环节是否可靠。指标定义以 `06-评估与验收方案.md` 为准。

### 2.3 学习目标

1. 完整经历需求分析、方案设计、数据采集、算法实现、对照实验、结果评估与汇报的工程闭环。
2. 掌握传统特征工程与迁移学习在小样本条件下的适用边界与取舍方法。
3. 掌握数据泄漏的识别与防范方法，特别是同一文档页多角度拍摄导致的分组泄漏。
4. 掌握在样本量有限时正确汇报指标与置信区间的方法。

## 3. 项目范围

### 3.1 范围内工作

1. 在校内采集斜拍文档照片 200 至 320 张，载体覆盖投影幕布、黑板板书与纸质笔记。v3 实际合格 340 张；2026-11-27 新增两批 102 张后 v4 合格 442 张，手册数量为建议值（D-02）。
2. 实现文档四边形定位与透视变换矫正。
3. 实现反光抑制与对比度增强，主要方法为限制对比度自适应直方图均衡。
4. 实现页面级内容二分类（文字/公式），载体作为辅助属性。
5. 完成传统机器学习基线与轻量卷积神经网络的量化对比、消融实验与错误案例分析。
6. 完成实验报告、汇报演示文稿与可视化图组。
7. 隐私信息检测与打码工具：本组自设扩展功能，按决定 D-01 取消开发（非课程要求）；数据清洗已完成，敏感样本排除出数据集与对外使用。
8. 实现本机网页交互界面：拍照/相册/文件上传，展示检测、矫正、扫描件与分类结果，支持批量队列、四角拖拽调整、点击放大与 PDF 导出。

### 3.2 范围外工作

1. 不实现光学字符识别，不还原公式的数学表达式。系统只判断页面是否属于公式页。
2. 不处理视频流，不实现实时矫正。
3. 不开发移动应用、多用户服务与公网部署。交付形式为命令行工具、脚本与本机单用户网页演示。
4. 不处理曲面书页展开，仅处理平面文档的透视畸变。
5. 不处理严重遮挡样本。四角被遮挡的照片视为不合格样本，不进入测试集。
6. 不提供通用匿名化服务，打码功能仅服务于本项目数据集的对外使用。

## 5. 成功标准

项目判定为成功，须同时满足以下六项条件。

1. 指标条件。独立测试集内容分类准确率不低于 85%，并给出两种技术路线的量化对比表。
2. 过程条件。评估数据集为校内自采且可追溯，样本清单与留证照片齐全；外部公开数据只用于预训练初始化或仅训练辅助，不进入自采评估集，来源与用途已披露。
3. 复现条件。另一名组员在干净容器中按说明文档操作，可复现主结果，准确率偏差不超过 0.5 个百分点。
4. 展示条件。提供六至八张未参与训练的测试图并排可视化结果，并对至少三类典型错误给出归因分析。
5. 合规条件。对外使用的图像不含可识别个人信息：含个人信息样本按 D-01 排除，不进入任何对外材料。
6. 交互条件。本机网页可拍照、从相册或文件上传，展示原图、四角、矫正图、扫描件与分类结果；支持批量队列、点击放大与 PDF 导出；自动检测失败时可拖拽四角重新计算。

## 6. 关键约束

| 编号 | 约束 | 影响 |
|---|---|---|
| C-01 | 数据须校内自采，不得使用公开数据集 | 采集与质检工作量前移，进度受场地与天气影响 |
| C-02 | 组员设备涵盖 ARM 与 x86 两种架构 | 须采用容器化方案并统一评估设备 |
| C-03 | 无图形处理器预算，训练在中央处理器上完成 | 深度学习只能采用轻量骨干网络与较小输入分辨率 |

| C-05 | 原始图像体积较大 | 图像文件不纳入版本控制，依靠清单保证可追溯性 |
| C-06 | 图像可能包含路人面部、二维码与文档内个人信息 | 敏感样本已按 D-01 排除；对外材料不得含个人信息，处理全程离线 |
