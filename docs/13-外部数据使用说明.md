# 外部数据使用说明

| 项目 | 内容 |
|---|---|
| 日期 | 2026-11-27 |
| 课程口径 | 课程要求未禁止外部数据；本组将其限定为**预训练辅助 + 仅训练辅助**，并在报告中披露 |
| 使用范围 | 可用于 CNN 初始化、纸质稿内容辅助训练与载体门控训练；不进入自采样本清单、`split_v3`、验证集或测试集 |
| 评估口径 | 最终指标仍只在自采验证集/测试集上计算；外部验证只用于早停与诊断 |
| 数据清单 | `data/manifests/external_aux.csv`、`paper_content.csv`、`carrier_gate.csv`，逐行记录路径、标签、来源与划分 |

## 1. 数据来源与数量

| 来源 | 用途 | 数量 | 许可 |
|---|---|---:|---|
| IM2LATEX-100K | 公式类预训练 | 1,200 | CC0-1.0（镜像声明） |

合计 2,400 张，公式/文字各 1,200。图片本体仍在 `data/raw_samples/external-assets/`，不复制、不进入版本控制。

2026-11-27 起，外部数据另有两个**仅训练**用途：

| 清单 | 用途 | 训练/验证 | 说明 |
|---|---|---|---|
| `paper_content.csv` | 纸质稿内容二分类辅助训练 | 1,033 / 30 | 自采 paper + 外部 A4/公式数据；验证集全部为自采 paper，外部数据不进入验证 |
| `paper_content_extctl.csv` | 外部文本对照（仅 SmartDoc + Tobacco Scientific） | 894 / 30 | 只用于对照实验，外部部分无公式图；验证集为自采 paper |
| `carrier_gate.csv` | PPT/纸质稿载体门控 | 2,236 / 1,000 | SCB 屏幕 + 外部 A4 + 自采 train；自采 val 只评估 |

这两份清单不改变“外部数据不得进入自采 val/test”的底线。其中 `paper_content.csv` 另抽取 IM2LaTeX 公式 400 张、外部文本页 500 张；`carrier_gate.csv` 另抽取外部文本页 1,000 张（训练）与 500 张（验证）作为纸质负类。

## 2. 使用方式

```bash
# 1) 生成外部清单（可复现，固定随机种子）
PYTHONPATH=src python scripts/build_external_dataset.py --formula 1200 --text 1200

# 2) 外部预训练，只保存初始化权重
PYTHONPATH=src python scripts/pretrain_external.py \
  --out runs/pretrain-external-01 --epochs 2 --input-size 160

# 3) 自采数据微调，验证/测试仍只用自采
PYTHONPATH=src python scripts/train_cnn.py \
  --exp-id exp-cnn-ext-01 --epochs 15 --freeze-epochs 3 --no-enhance \
  --corners-policy fallback \
  --init-checkpoint runs/pretrain-external-01/backbone.pt

# 4) 纸质稿内容辅助训练（自采 paper + 外部 A4）
PYTHONPATH=src python scripts/build_paper_content_manifest.py
docker run --rm -v "$PWD:/app" -w /app -e PYTHONPATH=/app/src:/app \
  docnorm:cpu-arm64 python scripts/train_paper_classifier.py \
  --manifest data/manifests/paper_content.csv --out runs/paper-cnn-01 \
  --epochs 6 --freeze-epochs 3 --input-size 224 --batch-size 32 --patience 2

# 5) 载体门控（PPT/幕布 vs A4 纸质稿）
PYTHONPATH=src python scripts/build_carrier_gate_manifest.py
docker run --rm -v "$PWD:/app" -w /app -e PYTHONPATH=/app/src \
  docnorm:cpu-arm64 python scripts/train_screen_gate.py \
  --manifest data/manifests/carrier_gate.csv --out runs/carrier-gate-01 \
  --epochs 3 --input-size 160 --batch-size 48 --patience 2
```

## 3. 边界

1. `external_aux.csv` 的 `usage` 固定为 `pretrain`；`paper_content.csv` 与 `carrier_gate.csv` 仅用于训练，不得进入自采验证/测试，也不得据此报告最终指标。
2. 外部数据不得加入 `data/manifests/sample_manifest.csv`、`split_v3.json`、`manual_corners.csv` 或自采评估列表。
3. 外部预训练的验证集只用于早停和诊断，不用于最终指标。
4. 报告必须写明来源、数量、许可、用途与“不进入自采验证/测试”的边界；不得隐藏或删除来源。
5. 若课程对公开数据的使用有新的限制，以课程要求为准，停止新增外部数据实验；已经完成的辅助训练实验按原口径披露，不删除来源。

## 4. 报告写法建议

> 为缓解自采训练样本仅 236 张的限制，本组使用 IM2LATEX-100K、Tobacco-3482、IAM 与 SmartDoc 2015 的公开图像做 CNN 初始化（共 2,400 张，公式/文字各 1,200），再在自采训练集上微调；另以外部 A4 数据辅助训练纸质稿内容模型与 PPT/纸质稿载体门控。外部数据只进入训练集，不进入自采样本清单、验证集或测试集；最终指标只在自采 `split_v3` 上计算。来源、许可与用途见 `data/manifests/external_aux.csv`、`paper_content.csv`、`carrier_gate.csv` 与本说明。

## 5. 风险

1. 域差距：公开公式渲染图与教室幕布/纸质公式在字体、背景、光照上差异较大，预训练不一定提升，需以自采验证集结果为准。
2. 标签噪声：Tobacco 等数据只按文档体裁收集，二元“文字/公式”标签是弱标签；预训练阶段允许噪声，但不能据此报告分类指标。
3. 许可：IAM 为非商业研究用途；对外发布材料不复用其原图，只报告汇总结果。

## 6. 实测结果

| 阶段 | 结果 |
|---|---|
| 外部预训练 | 2,160 张训练 / 240 张外部验证，160 输入，2 轮；外部验证 93.3% |
| 自采微调（2,400 张预训练） | `exp-cnn-ext-01`：自采验证 76.5% / 宏 F1 74.2% |
| 小样本预训练（600 张，1 轮） | 外部验证 95.0% |
| 小样本自采微调（种子 42） | `exp-cnn-ext-02`：自采验证 82.35% / 宏 F1 81.32% |
| 小样本自采微调（种子 43） | `exp-cnn-ext-03`：自采验证 68.63% / 宏 F1 63.57% |
| 对照（种子 42 / 43） | 不使用外部数据：80.4% / 80.4% |
| 载体门控 `carrier-gate-01` | 2,236 训练 / 1,000 外部验证；外部与自采 val 51 张均全对 |
| 纸质稿专用 `paper-cnn-01` | 1,033 训练 / 30 自采纸质验证；70.00% / 宏 F1 69.70%，与现有 CNN 持平 |
| 外部文本对照 `paper-cnn-extctl` | 自采 + SmartDoc 500 + Scientific 261，894 训练 / 30 自采验证；平衡权重 3 种子 80.00%–86.67%，均值 83.33%；两组无权重种子 42 均为 66.67%，增益来自类别权重而非数据来源 |

载体门控的外部验证与训练同源，100% 只说明拟合了外部分布；自采验证仅 51 张，不能据此宣称线上稳定。

2,400 张外部预训练没有带来提升，反而使初始验证损失升高、13 轮后才恢复到 76.5%。原因主要是域差距：IM2LATEX 是干净渲染公式裁剪，Tobacco/IAM 是扫描文档/手写行，与教室幕布、黑板、纸质笔记的拍摄分布差异较大。

把外部样本降到 600 张、只预训练 1 轮后，`exp-cnn-ext-02`（种子 42）达到 82.35% / 81.32%，比纯自采基线多对 1 张验证图（`IMG_6206`），没有新增错误。但同配置换种子 43 后 `exp-cnn-ext-03` 只有 68.63% / 63.57%，早停在第 7 轮；无外部对照 `exp-cnn-10`（种子 43）为 80.39% / 79.44%。

结论：600 张外部预训练的 82.35% 是种子 42 的峰值，不具跨种子稳定性；外部内容预训练在本数据上不采用。载体门控可作为预处理分支候选；纸质稿专用模型无增益，暂不接入；零样本直接使用已否决，详见下节与 ADR-0016。

### 6.1 网页接入

2026-11-27 网页主链路已接入载体门控与双分支分类：门控 → 纸质稿 CNN 集成 / PPT CNN → SVM 兜底。纸质分支使用 `paper-cnn-extctl-01/43/44` 三个种子的概率平均，验证集路由准确率 88.24% / 宏 F1 88.01%。需要注意，纸质分支的增益与公式类权重相关，不能据此认定 SmartDoc/Scientific 数据来源本身更优；详见 `reports/web_integration.md` 与 `reports/external_control.md`。

## 7. 零样本直接测试（2026-11-27）

把 `pretrain-external-01` 与 `pretrain-external-small` 直接用在自采 340 张真实数据上（自动四角 + 人工回退 + 拉正，不增强）：

| 模型 | 外部验证 | 真实 340 张 | formula 召回 |
|---|---:|---:|---:|
| `pretrain-external-01` | 93.3% | 54.41% | 0.00% |
| `pretrain-external-small` | 95.0% | 54.41% | 2.58% |
| 多数类基线（全判 text） | — | 54.41% | 0.00% |

外部预训练权重在真实拍摄页上退化为“全判 text”，不能直接使用。详细分层结果、原因与复现命令见 `reports/pretrained_zero_shot.md`。下一步只考虑域适配方案（合成整页、patch 级检测或补自采公式页），不再扩大裁剪图预训练。

## 8. 公开 PPT 幕布数据调研

截至 2026-11-26 的检索结果：**没有找到可直接下载、带“文字/公式”标签的投影幕布 PPT 实拍数据集**。最接近的公开资源如下：

| 资源 | 内容 | 与本任务的距离 |
|---|---|---|
| LecSlides-370K（ICCV 2025） | 370,078 张数字讲义幻灯片，来自 SlideShare | 数字幻灯片，不是投影幕布实拍；无文字/公式二分类标签 |
| SlideVQA | 52,380 张数字幻灯片与问答 | 同上，偏问答 |
| LPM Dataset（GitHub `dondongwon/LPMDataset`） | 9,000+ 张从教学视频提取的幻灯片 | 数字幻灯片，不是教室投影拍摄 |
| SynSlide / RealSlide | 合成/真实数字幻灯片版面数据 | 版面检测与检索，不是投影拍摄 |
| Projection Screen Detection（YOLOv7 论文） | 约 2,000 帧演示视频中的投影幕布框 | 只做屏幕定位，不做文字/公式分类；是否公开下载不明确 |
| SCB-Dataset | 教室行为数据，含 screen/blackboard 框 | 行为识别，不是课件内容分类 |

结论：

1. 现有公开数据要么是**数字幻灯片**（无投影畸变、反光、环境光），要么只做**屏幕/行为检测**，都不能直接补足“投影幕布 PPT 的文字/公式识别”。
2. 继续用 IM2LATEX/Tobacco/IAM 做大规模预训练，会进一步把模型拉向“干净公式裁剪/扫描文档”，对教室 PPT 反而不友好。
3. 因此将外部预训练样本量从 2,400 降到 **600（公式 300 + 文字 300）**，只跑 1 轮，作为低强度初始化对照；若仍无收益，最终方案不使用外部预训练。外部数据仍可用于纸质稿内容与载体门控的辅助训练，边界见第 3 节。
4. 更合适的方向是**合成投影 PPT 页面或合成“公式嵌入纸张”整页**：用 IM2LATEX 公式与文字模板生成页面，再叠加透视、光照与反光；合成样本仅进训练集并披露。该方向登记为 OQ-10，确认后再做。
