# 外部数据使用说明

| 项目 | 内容 |
|---|---|
| 日期 | 2026-11-26 |
| 课程口径 | 课程要求未禁止外部数据；本组将其限定为**预训练辅助**，并在报告中披露 |
| 使用范围 | 仅用于 CNN 初始化；不进入自采样本清单、`split_v3`、验证集或测试集 |
| 评估口径 | 最终指标仍只在自采验证集/测试集上计算 |
| 数据清单 | `data/manifests/external_aux.csv`，逐行记录路径、标签、来源、许可与用途 |

## 1. 数据来源与数量

| 来源 | 用途 | 数量 | 许可 |
|---|---|---:|---|
| IM2LATEX-100K | 公式类预训练 | 1,200 | CC0-1.0（镜像声明） |
| Tobacco-3482 | 文字类预训练 | 900 | 研究用途；镜像标注 Apache-2.0 |
| IAM Handwriting (FineVision) | 手写文字类预训练 | 180 | 非商业研究用途 |
| SmartDoc 2015 Challenge 1 | 文档场景文字类预训练 | 120 | CC BY 4.0 |

合计 2,400 张，公式/文字各 1,200。图片本体仍在 `data/raw_samples/external-assets/`，不复制、不进入版本控制。

## 2. 使用方式

```bash
# 1) 生成外部清单（可复现，固定随机种子）
PYTHONPATH=src python scripts/build_external_dataset.py --formula 1200 --text 1200

# 2) 外部预训练，只保存初始化权重
PYTHONPATH=src python scripts/pretrain_external.py \
  --out runs/pretrain-external-01 --epochs 2 --input-size 160

# 3) 自采数据微调，验证/测试仍只用自采
PYTHONPATH=src python scripts/train_cnn.py \
  --exp-id exp-cnn-ext-01 --epochs 15 --freeze-epochs 3 --no-enhance \
  --corners-policy fallback \
  --init-checkpoint runs/pretrain-external-01/backbone.pt
```

## 3. 边界

1. `external_aux.csv` 的 `usage` 固定为 `pretrain`，不得改成 `train` 或 `eval`。
2. 外部数据不得加入 `data/manifests/sample_manifest.csv`、`split_v3.json`、`manual_corners.csv` 或自采评估列表。
3. 外部预训练的验证集只用于早停和诊断，不用于最终指标。
4. 报告必须写明来源、数量、许可、用途与“仅预训练”边界；不得隐藏或删除来源。
5. 若课程对公开数据的使用有新的限制，以课程要求为准，停止外部预训练实验。

## 4. 报告写法建议

> 为缓解自采训练样本仅 236 张的限制，本组使用 IM2LATEX-100K、Tobacco-3482、IAM 与 SmartDoc 2015 的公开图像做 CNN 初始化（共 2,400 张，公式/文字各 1,200），再在自采训练集上微调。外部数据仅用于预训练，不进入自采样本清单、验证集或测试集；最终指标只在自采 `split_v3` 上计算。来源与许可见 `data/manifests/external_aux.csv`。

## 5. 风险

1. 域差距：公开公式渲染图与教室幕布/纸质公式在字体、背景、光照上差异较大，预训练不一定提升，需以自采验证集结果为准。
2. 标签噪声：Tobacco 等数据只按文档体裁收集，二元“文字/公式”标签是弱标签；预训练阶段允许噪声，但不能据此报告分类指标。
3. 许可：IAM 为非商业研究用途；对外发布材料不复用其原图，只报告汇总结果。

## 6. 实测结果

| 阶段 | 结果 |
|---|---|
| 外部预训练 | 2,160 张训练 / 240 张外部验证，160 输入，2 轮；外部验证 93.3% |
| 自采微调 | `exp-cnn-ext-01`：自采验证 76.5% / 宏 F1 74.2% |
| 对照 | 不使用外部数据：自采验证 80.4% / 宏 F1 79.0% |

外部预训练没有带来提升，反而使初始验证损失升高、13 轮后才恢复到 76.5%。原因主要是域差距：IM2LATEX 是干净渲染公式裁剪，Tobacco/IAM 是扫描文档/手写行，与教室幕布、黑板、纸质笔记的拍摄分布差异较大。该结果作为负面对照保留，最终模型不加载外部预训练权重。
