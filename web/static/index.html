关于本项目

本系统面向课堂场景的斜拍文档：输入手机或相机拍摄的投影幕布、黑板板书或纸质笔记照片， 完成文档四角定位与透视矫正，并判定页面内容属于纯文字还是含公式。系统同时提供扫描件输出、 批量队列、四角校准与 PDF 导出，用于课堂演示与文档归档。

课程：武汉理工大学《机器学习》课程工程实践 · 第六组 · Task 06。 项目源码与完整开发历程见 GitHub 仓库。

“矫正”的口径

输入一张斜拍原图，系统定位文档四边，估计四个顶点，执行透视变换，输出正面矫正图。 “矫正”指几何透视矫正，目标是让文档平面与图像平面平行；它不承诺恢复已经被镜面反光、 过曝或运动模糊完全丢失的文字信息。

  • 分类路径：OpenCV Canny（PPT/纸质均为 50/150）、形态学闭运算、轮廓查找与四边形近似， 通过面积与凸性校验后做四点透视变换。检测失败时保留原图并标记 rectify_failed，避免错误裁切放大误差。
  • 显示/PDF 路径：MobileNetV3-Small 回归 8 个归一化坐标，按 PPT/纸质分别训练； 用于在自动检测失败或用户需要更贴合边界的矫正图时提供显示与导出视图。 两条路径共享原图与人工四角，用户手动应用四角后同时切换。
  • 分类与显示解耦：内容分类固定使用 OpenCV 视图，保证指标口径稳定； “学习四角”视图只影响矫正图、扫描件与 PDF，不参与分类指标。
  • 增强与扫描件：CLAHE 与自适应阈值用于显示与扫描件（白底黑字）， 不进入分类输入，避免增强造成的分布漂移。

测试集 72 张中 61 张自动拉正成功；11 张失败按原图分类并在结果中标记。 “矫正成功”不等于“分类正确”，两者分别记录、分别分析。

“分类”的口径

内容分类采用二分类评估口径：text（纯文字为主）与 formula（含数学公式）。 数据集归档仍保留四格标签 ppt_text / ppt_formula / paper_text / paper_formula， 用于数据管理与分层统计；评估时按 label_map 映射为二分类（ADR-0008）。

  • 载体门控：先判定投影幕布（PPT）或纸质/板书，再进入对应分支； 门控低置信时标记 uncertain，允许用户手动重试另一分支，不自动跨分支切换。
  • 分支模型：PPT 分支使用 MobileNetV3-Small；纸质分支使用两个种子的 CNN 概率平均； 模型缺失时回退传统 SVM。结果卡展示载体、命中分支、文字/公式概率与处理耗时。
  • 指标：准确率、宏平均 F1、混淆矩阵、按载体分组与分类别召回； 测试集只做一次性评估，不用于阈值选择、早停或模型选择。

v5 测试集一次性评估为 93.06% / 宏 F1 92.65%；自采 42 张 88.10%，外部 30 张 100%， 公式召回 83.33%。外部 30 张全部为纸质文字页，不代表公式能力；合计 Wilson 95% 置信区间 下界约 84.8%，低于 85%，因此“达标”仅指合计点估计，不能表述为稳健达标。

数据、评估与边界

  • 当前划分 split_v5：训练 349 / 验证 51 / 测试 72；自采 442 张，外部测试 30 张只进 test。
  • 同一文档页的多角度照片按 doc_page_id 整组划分，避免跨集合泄漏。
  • 测试集不参与训练、阈值选择或早停；v4 的 67.92% 仅作历史对照，不与 v5 混用。
  • 提交包权重为事故后恢复重建版，测试复评 90.28%；正式结果 93.06% 以原权重一次性评估记录为准。
  • 自动隐私打码按 D-01 取消开发；含个人信息样本已从数据集与对外材料中剔除。

About this project

This system handles obliquely photographed classroom documents: projection screens, blackboard notes, or paper notes. It locates the four corners, applies perspective rectification, and classifies the page as text-only or formula-bearing. It also provides scan output, batch queues, corner adjustment and PDF export.

Course: Wuhan University of Technology, Machine Learning Engineering Practice · Group 06 · Task 06. Source code and full development history: GitHub.

What “rectification” means

Rectification is geometric: detect the document boundary, estimate four corners, and apply a perspective warp to produce a frontal view. It does not recover information lost to glare, overexposure or motion blur.

  • Classification path: OpenCV Canny 50/150, morphology, contour and quadrilateral fitting, area/convexity checks, then a four-point warp. Failures keep the original image and are marked rectify_failed.
  • Display/PDF path: MobileNetV3-Small regresses eight normalized corner coordinates; it is used for display and export views, not for classification metrics. Both paths share the original image and manual corners.
  • Enhancement: CLAHE and adaptive thresholding are used for display and scan output only, and are not fed to the classifier.

On the 72-image test set, 61 images were auto-rectified and 11 fell back to the original image. Rectification success is not the same as classification correctness.

What “classification” means

Evaluation uses a two-class content label: text vs formula. The four archive labels (ppt_text / ppt_formula / paper_text / paper_formula) are for data management and are mapped to the two-class evaluation label (ADR-0008).

  • Carrier gate: PPT/screen vs paper/blackboard first; low-confidence samples are marked uncertain and can be retried manually; no automatic cross-branch switch.
  • Branches: PPT MobileNetV3-Small; paper CNN ensemble of two seeds; SVM fallback. The result card shows carrier, branch, probabilities and latency.
  • Metrics: accuracy, macro F1, confusion matrix, per-carrier and per-class recall. The test set is evaluated once and is not used for threshold selection or early stopping.

v5 test: 93.06% / macro F1 92.65%; self-collected 42 images 88.10%, external 30 images 100%, formula recall 83.33%. External 30 are all paper text pages; the overall Wilson 95% CI lower bound is about 84.8%, below 85%, so “passing” is a point estimate only.

Data and boundaries

  • split_v5: train 349 / val 51 / test 72; 442 self-collected images plus 30 external test images (test only).
  • Multi-angle photos of the same document page are grouped by doc_page_id and kept in one split.
  • The test set is not used for training, thresholding or early stopping; v4 67.92% is historical only.
  • Submitted weights are the recovered build; test re-evaluation is 90.28%; official 93.06% is the original-weight one-shot evaluation.
  • Automatic privacy masking was cancelled under D-01; samples with personal information were excluded.
